# 2026-08-20 훈련 및 확장 평가 명령

저장소 루트(`/scratch/workspace/eunbiyoon_umass_edu-paper/sal`)에서 실행한다.
GPU 노드에서 `nvidia-smi -L`로 GPU가 보이는지 먼저 확인한다.

## 1. Train

아래 명령은 새 세션 `extended_20260820` 아래에 여섯 LoRA variant를 훈련하고,
A+β-AUX와 A+β-ALL을 결합한 MERGE adapter를 생성한다. 기존 체크포인트는 수정하지 않는다.

```bash
cd /scratch/workspace/eunbiyoon_umass_edu-paper/sal

python scripts/prepare_paper_data.py --from-1000

export RUN_ID=extended_20260820
./scripts/run_paper_train.sh \
  --session "$RUN_ID" \
  --data-dir data/paper
```

훈련 중단 후 checkpoint에서 재개할 때:

```bash
cd /scratch/workspace/eunbiyoon_umass_edu-paper/sal
export RUN_ID=extended_20260820

./scripts/run_paper_train.sh \
  --session "$RUN_ID" \
  --data-dir data/paper \
  --resume
```

훈련 결과 위치:

```text
runs/extended_20260820/lora/filter_on/
runs/extended_20260820/lora/filter_off/
runs/extended_20260820/lora/core/
runs/extended_20260820/lora/aux/
runs/extended_20260820/lora/all/
runs/extended_20260820/lora/rw/
runs/extended_20260820/lora/merge/
```

## 2. Extended evaluation — 1,000 episodes/environment

훈련이 완료된 동일 세션의 checkpoint를 사용한다. `base`는 adapter가 없는
`Qwen/Qwen2.5-3B-Instruct`이며, 외부 API나 Bedrock은 호출하지 않는다.

```bash
cd /scratch/workspace/eunbiyoon_umass_edu-paper/sal

export RUN_ID=extended_20260820
export PYTHONHASHSEED=0

./scripts/eval_gpu.sh --extended \
  --episodes 1000 \
  --seed 42 \
  --lora-dir "runs/$RUN_ID/lora" \
  --variants base,filter_on,filter_off,core,aux,all,rw,merge \
  --out-dir results/extended_eval_1000
```

같은 명령을 다시 실행하면 `episode_rewards.csv`에 이미 저장된 episode를 건너뛰고
나머지 평가를 이어서 실행한다.

평가 결과 위치:

```text
results/extended_eval_1000/episode_rewards.csv
results/extended_eval_1000/summary_by_model_env.csv
results/extended_eval_1000/pairwise_comparisons.csv
results/extended_eval_1000/*.png
```

추론 없이 CSV에서 통계와 plot만 다시 생성할 때:

```bash
cd /scratch/workspace/eunbiyoon_umass_edu-paper/sal
python -m eval.extended_eval \
  --analyse-only \
  --out-dir results/extended_eval_1000
```
